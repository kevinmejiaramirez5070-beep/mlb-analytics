# Imágenes de Fondo

Coloca aquí las imágenes que quieras usar como fondo de la página.

## Formatos recomendados:
- JPG, PNG, WebP
- Resolución: 1920x1080 o superior
- Tamaño: máximo 2MB

## Nombres sugeridos:
- `baseball-stadium.jpg`
- `baseball-field.jpg`
- `mlb-background.jpg`
- `stadium-night.jpg`

## Instrucciones:
1. Coloca tu imagen en esta carpeta
2. Renómbrala como `background.jpg`
3. La página la usará automáticamente como fondo
